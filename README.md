Sakthi Dental Clinic — Website

A modern, responsive dental clinic website for **Sakthi Dental Clinic**, Hosur. Built to showcase services, introduce the team, answer patient questions, and make it easy for families to get in touch.

**Live demo:** [dental-clinic-cyan-ten.vercel.app](https://dental-clinic-cyan-ten.vercel.app/)

---

## Features

### Pages
- **Home** — Hero section with clinic tagline, stats (10,000+ smiles, 4.9/5 trust, 20+ years), service highlights, why-choose-us grid, treatments preview, and patient testimonials
- **About** — Doctor profile (Dr. Anupriya), clinic history, vision & mission, and full team directory with specialisations
- **Treatments** — Card-based listing of all dental services: cleaning, filling, extraction, bleaching, orthodontics, dentures, and more
- **FAQs** — 14 accordion-style Q&A entries covering common patient concerns about pain, procedures, hygiene, and maintenance
- **Contact** — Contact form (name, email, phone, message) alongside full clinic address, phone numbers, email, and operating hours
- **Privacy Policy** — Dedicated policy page

### UX & Design
- Fully responsive layout — works on mobile, tablet, and desktop
- Sticky header with navigation links and a prominent CTA button ("Fix Appointment")
- Smooth page-to-page navigation
- Consistent footer with quick links, contact details, and tagline
- Clean, trust-first visual style suited for a family healthcare audience
- Accessible, semantic HTML structure
